# Дизайн: кнопка редактирования на Архиве и общий футер

Дата: 2026-09-17
Статус: утверждён

## Задачи

1. Ссылку «Редактировать розыгрыши» перенести с футера главной на вкладку
   «Архив» — кнопкой вверху.
2. Общий футер внизу обеих страниц: версия приложения, ссылка на GitHub
   проекта, кнопка «наверх».

## Решения, принятые при обсуждении

- Ссылка «← К генератору» на странице админки **сохраняется** над общим
  футером — явный путь назад без кнопки браузера.
- Версия прошивается в бинарь **через `-ldflags -X`** (вариант
  `debug.ReadBuildInfo()` отвергнут: `.dockerignore` исключает `.git`, в
  Docker-образе VCS-информации нет — основной способ деплоя остался бы без
  версии).

## 1. Кнопка «Редактировать розыгрыши» на Архиве

В `web/index.html` внутрь `#tab-archive` сверху добавляется ссылка на
`/admin`, оформленная как `btn-secondary` (для якоря добавляется
`display: block` в CSS — ширина как у карточек). Видна только на вкладке
«Архив». Старый `<footer>` с этой ссылкой из `index.html` удаляется.

## 2. Общий футер

Одинаковый блок в конце `<body>` обеих страниц (`index.html`, `admin.html`):

```html
<footer class="site-footer">
  <span id="app-version" hidden></span>
  <a href="https://github.com/huhen/fortunata">GitHub</a>
  <button id="btn-top" type="button">↑ Наверх</button>
</footer>
```

Горизонтальная строка по центру, приглушённые цвета — как у текущего футера;
все элементы помещаются в одну строку на мобильной ширине. Разметка
дублируется в двух файлах: шаблонизации в проекте нет, ради трёх строк она не
не нужна.

«↑ Наверх» — плавная прокрутка: `window.scrollTo({ top: 0, behavior: 'smooth' })`.

## 3. Версия

- Новый пакет `internal/version` с единственной переменной
  `var Version = "dev"` — дефолт для локального `go run`.
- `.github/workflows/release.yml`: вычисленный `$VERSION` подставляется
  в обоих шагах сборки (бинарь — через `-ldflags`, docker-образ — через
  build-arg): `-X fortunata/internal/version.Version=$VERSION`.
- `Dockerfile`: `ARG VERSION=dev` + та же `-X` в ldflags сборки.
- Выдача фронту: публичный `GET /api/version` → `{"version": "..."}` —
  версия не секрет; ручка без сессии, как `GET /api/draws`.
- Пакетная переменная вместо параметра в `api.New`/`newHandler` — чтобы не
  менять сигнатуры и три тестовых вызова `newHandler`.
- Новый `web/footer.js`, подключаемый обеими страницами: заполняет
  `#app-version` (при сбое запроса элемент остаётся скрытым), вешает
  обработчик на «↑ Наверх». `common.js` остаётся чистыми хелперами без
  побочных эффектов.

## Не входит в объём

- Плавающая кнопка «наверх», появляющаяся при скролле, — кнопка живёт
  в футере.
- Отображение версии на админке отдельно от футера.
- Тесты фронтенда на футер (в проекте тестируется только парсер).

## Проверка

- Go-тест: `GET /api/version` отдаёт JSON с версией.
- `go test ./...` и `node --test web/parse.test.mjs` — зелёные.
- Вручную (`ADMIN_PASSWORD=test go run ./cmd/server`): кнопка на Архиве
  ведёт на `/admin`; футер на обеих страницах; версия — `dev`; «↑ Наверх»
  прокручивает страницу; сборка с `-ldflags -X` подменяет версию.
